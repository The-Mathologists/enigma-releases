# Enigma

The Mathologists' private team messenger, in the Mac menu bar.

**Download (staging):** [Enigma.dmg](https://github.com/The-Mathologists/enigma-releases/releases/latest/download/Enigma.dmg)

1. Open the downloaded `Enigma.dmg`.
2. Drag **EnigmaStaging** into **Applications**.
3. Open EnigmaStaging from Applications and sign in with TM Auth.

These are staging builds; production comes later. Enigma keeps itself up to date — you never need to download it again.

_This repository only hosts the app downloads and the update feed (`appcast-staging.xml`)._
